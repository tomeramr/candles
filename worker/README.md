# קורא נרות פרו – הקמה

הגרסה בתשלום נמצאת בתיקייה `pro/` (כתובת: https://tomeramr.github.io/candles/pro/).

**איך היא מוגנת:**
- באתר עצמו אין את האפליקציה. יש רק דף כניסה, והאפליקציה המוצפנת נמצאת ב-`pro/app.enc`.
- רק השרת הקטן בתיקייה הזו מחזיק את מפתח הפענוח. הוא בודק את הסיריאל מול Lemon Squeezy, ורק אם הסיריאל בתוקף, מפענח את האפליקציה ושולח אותה, חתומה עם הסיריאל ועם המייל של הלקוח. מפתח הפענוח לא מגיע לדפדפן אף פעם.
- כל סיריאל נבדק שוב בכל פתיחה (לכל היותר כל 10 דקות) ובזמן שימוש (כל שעה). סיריאל שפג נחסם, והאירוע נרשם ביומן.
- קודי אורח לחברים נוצרים בלוח המנהל, נבדקים בשרת בכל כניסה, ואפשר לבטל אותם מיד.
- לכל כתובת IP יש הגבלת קצב (למשל 8 ניסיונות כניסה בדקה).

## 1. Lemon Squeezy (תשלומים ומפתחות רישיון)

1. נרשמים ב-lemonsqueezy.com ופותחים חנות (Store).
2. Products → New product → **קורא נרות פרו**:
   - Pricing: **Subscription**. שתי אפשרויות (Variants): חודשי 39 ₪, שנתי 349 ₪.
   - **Free trial: 5 days**.
   - מסמנים **Generate license keys**. Activation limit: **3**. License length: **Unlimited** (המפתח פג לבד כשהמנוי נגמר).
3. רושמים בצד:
   - **Store ID**: Settings → Stores (המספר ליד שם החנות).
   - **Product ID**: בעמוד המוצר (לא חובה).
   - **API key**: Settings → API → New key.
   - **קישור לרכישה**: בעמוד המוצר → Share → Checkout link.
   - **קישור לניהול מנוי**: `https://<שם-החנות>.lemonsqueezy.com/billing`.
4. כדאי להתחיל ב-**Test mode** ולבדוק שמנוי ניסיון שולח מפתח רישיון במייל.

## 2. Cloudflare (השרת)

1. נרשמים ב-cloudflare.com (חינם).
2. **Storage & Databases → D1 → Create** בשם `candles-pro`. נכנסים ל-**Console**, מדביקים את התוכן של `schema.sql` ולוחצים Execute.
3. **Workers & Pages → Create → Worker** בשם `candles-pro` → Deploy → **Edit code**. מוחקים את מה שיש, מדביקים את `worker.js`, ולוחצים **Deploy**.
4. ב-Worker: **Settings → Bindings → Add → D1 database**. Variable name: `DB`, ובוחרים את `candles-pro`.
5. **Settings → Variables and Secrets → Add**:

| שם | סוג | ערך |
| --- | --- | --- |
| `CONTENT_KEY` | Secret | המפתח שקיבלת בצ'אט (או `GATE_PW=... python3 tools/build_pro.py --print-key`) |
| `ADMIN_TOKEN` | Secret | קוד מנהל חדש וארוך (לפחות 24 תווים). לא את הקוד הישן מהצ'אט |
| `LS_API_KEY` | Secret | ה-API key מ-Lemon Squeezy |
| `LS_STORE_ID` | Text | ה-Store ID |
| `LS_PRODUCT_ID` | Text | ה-Product ID (לא חובה) |

6. מעתיקים את כתובת ה-Worker, למשל `https://candles-pro.<שם>.workers.dev`.
7. (מומלץ, חינם) **Security → WAF → Rate limiting rules**: כלל שחוסם כתובת ששולחת יותר מ-60 בקשות בדקה ל-Worker. זו שכבת הגנה נוספת מעל ההגבלה שכבר בנויה בשרת.

## 3. מחברים את האתר

עורכים ב-GitHub את `pro/config.json` (אפשר מהטלפון: פותחים את הקובץ → ✏️):

```json
{
  "api": "https://candles-pro.<שם>.workers.dev",
  "checkout": "<קישור הרכישה>",
  "portal": "https://<שם-החנות>.lemonsqueezy.com/billing",
  "contact": "<כתובת המייל ליצירת קשר>"
}
```

הכפתור "5 ימי ניסיון חינם", "ניהול מנוי" ו"צור קשר" יופיעו לבד אחרי השמירה.

## 4. לוח המנהל

באתר שלך (https://tomeramr.github.io/candles/), אחרי כניסה כמנהל: ⚙️ הגדרות → **📈 לוח מנהל**. בפעם הראשונה פותחים "הגדרות חיבור" ומדביקים את `ADMIN_TOKEN`.
בלוח: מנויים, מחוברים עכשיו, גרסאות, **🎟️ קודי גישה לחברים** (יצירה וביטול) ו**📜 יומן סיריאלים**: מתי כל סיריאל התחיל, נכנס, הוסיף מכשיר, נדחה, ומתי פג תוקפו.

## עדכון הגרסה בתשלום אחרי שינוי באפליקציה

```
GATE_PW=<סיסמת המנהל> python3 tools/build_pro.py
```

הסקריפט לוקח את האפליקציה מ-`index.html`, מוריד ממנה את כלי המנהל, ומצפין אותה מחדש ל-`pro/app.enc`.
אפשר להחליף את מפתח ההצפנה (למשל פעם בחודש) עם `--key-version 2`, ואז לעדכן את `CONTENT_KEY` ב-Cloudflare.

## מספר גרסה

מספר הגרסה כתוב בשורה אחת בתוך האפליקציה: `<meta name="app-version" content="2.0.0" data-date="24.11.2026">`.
בכל עדכון מעלים אותו (תיקון קטן: 2.0.1, תוספת: 2.1.0, שינוי גדול: 3.0.0) ומריצים את `build_pro.py`.
הסקריפט כותב את `version.json` באתר שלך וב-`pro/`. כל מי שהאפליקציה פתוחה אצלו יקבל בתוך עד חצי שעה פס "גרסה חדשה זמינה".
בלוח המנהל, ליד כל משתמש מופיעה הגרסה שרצה אצלו (⚠️ = גרסה ישנה).

## מה נשמר בשרת

לכל סיריאל: hash של הסיריאל (לא הסיריאל עצמו), 4 התווים האחרונים, שם ומייל מ-Lemon Squeezy, מצב, מועד הסיום ויומן אירועים. לכל מכשיר: שם המכשיר, גרסת האפליקציה ומועד הכניסה האחרונה. לקודי אורח: hash של הקוד, שם החבר ותאריך התפוגה.
